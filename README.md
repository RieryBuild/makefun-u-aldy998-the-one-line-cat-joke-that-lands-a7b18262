One one-line joke about cats, entered in the [The One-Line Cat Joke That Lands](https://make.fun/bounty/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262) bounty on make.fun.

The joke is **"My cat sleeps on my pillow just to harvest my hair ties; I'm convinced she's running a black-market elastic empire."** — 115 characters. The setup is cosy and innocent: the cat sleeps on my pillow, right where a loving cat belongs. The turn reframes the cuddle as a heist: she is only there to harvest my hair ties, and the punchline escalates the theft into a criminal enterprise run from my own bed. No saturated trope — no 3 a.m. zoomies, no knocked-over glass, no keyboard, no landlord, no box, no vet, no performance review — just a fresh angle on a theft every cat owner recognises.

## Run it

```sh
python3 main.py
```

This writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline. Standard library only.
